# User Stories

## Outline User Roles

- **Route Setter:** someone who builds new routes on the wall and keeps them up to date.
- **Climber:** someone who browses routes, finds ones at their level, and tries them at the gym.

## Draft User Stories

1. As a route setter, I want to click on holds on the wall, so that I can build a new route quickly.
2. As a route setter, I want to mark which holds are for starting and which one is the finish, so that climbers know where to begin and where to end.
3. As a route setter, I want to give my route a name and a grade, so that people can find it and know how hard it is.
4. As a route setter, I want to edit a route I already saved, so that I can fix a mistake or make it easier or harder.
5. As a route setter, I want to delete a route, so that old routes don't clutter up the list.
6. As a route setter, I want the app to stop me from saving a route with no start or finish hold, so that I don't post a route nobody can follow.
7. As a route setter, I want to reset the wall back to the starter routes, so that I can start fresh when I'm testing things out.
8. As a climber, I want to see all the routes in one place, so that I can pick something to try.
9. As a climber, I want to filter routes by grade, so that I only see the ones at my level.
10. As a climber, I want to sort routes from easiest to hardest, so that I can work my way up.
11. As a climber, I want to open a route on its own page, so that I can see exactly which holds to use.
12. As a climber, I want to send a friend a link to a route, so that we can try the same problem together at the gym.
13. As a climber, I want to take a quick look at a route without leaving the list, so that I can browse faster.
